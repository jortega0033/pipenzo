# Pipenzo Asset Index

This package is the production export of the approved Pipenzo mascot and brand system. The Field Engineer is the canonical mascot; Commander, Recon, Inspector, Auditor, and Ready are role/loadout states of the same operator.

## Brand
- `brand/pipenzo-helmet-p-glyph-*.svg` — monochrome helmet + p brand glyph.
- `brand/pipenzo-lockup-*` — horizontal and stacked lockups for dark/light backgrounds.
- `brand/pipenzo-wordmark-*` — wordmark-only assets.
- `app-icons/` — 1024 master, SVG, ICO, ICNS, and raster icon sizes.

## Detailed mascot
- `pipenzo-field-engineer-canonical-fullbody` — primary character master.
- `pipenzo-field-engineer-canonical-bust` — portrait/bust.
- `neutral`, `working`/`terminal`, `inspect`, `review`, `ready`, `refuse` — canonical state art.
- `commander-routing`, `recon-refine`, `inspector-review`, `auditor-verify` — role variants of the same operator.

## Mini heads and sprites
Use `mascot/mini/` for 32–512 px decorative/state portraits and `mascot/sprites/` for compact 32–96 px full-body state assets. Below 32 px, prefer the helmet+p brand icon rather than the mascot.

## Marketing
- `pipenzo-github-social-preview-1280x640-upload.jpg` — optimized GitHub upload asset.
- `pipenzo-github-social-preview-1200x630.*` — compatibility/social variant.
- `pipenzo-readme-hero-1600x520.*` — README hero.
- `pipenzo-landing-hero-1600x900.*` — landing-page hero.

## Illustrations
Includes scope/refusal, review, human approval, first-run, review-complete, ready-for-approval, workflow roles, and approved signature scenes.

## Formats
- SVG: functional brand/icon assets.
- PNG: lossless masters and transparent mascot art.
- WebP: web deployment copies.
- JPG: GitHub upload-optimized social preview.
- ICO/ICNS: platform application icons.
